# Canonical visual references

This directory records immutable provenance for art used to derive CHIBAIT production assets.

The owner's canonical Chibi reference is fingerprinted in `SOURCE_MANIFEST.json`.

The original binary is intentionally not fabricated or re-encoded by the repository bootstrap step. When it is vendored, its bytes must match the recorded SHA-256 or the manifest must be versioned explicitly.

Production sprites belong elsewhere; this directory is for source/reference evidence.
